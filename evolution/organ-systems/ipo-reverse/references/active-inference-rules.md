# 主动推演规则

本 Skill 默认由 Agent 主动完成逆向推演。用户不是主要信息源，用户只用于校准高影响且无法自证的未知项。

## 1. 推演优先顺序

```text
产出物证据
→ 结构关系
→ 领域方法论
→ 专家常见路径
→ 假设标注
→ 必要时追问用户
```

先独立给出第一版过程模型，再决定是否追问。不要用连续提问代替推演。

## 2. 追问门槛

只有未知项同时满足 4 个条件才追问：

1. 影响最终 IPO 主链路。
2. 无法从产出物证据、结构关系、领域方法论推断。
3. 推错会导致复现路径明显失效。
4. 无法通过正向还原、删步反证或替代路径比较自验。

否则标证据等级和假设，继续推进。

## 3. 未知项处理

| 未知类型 | 判断标准 | 处理方式 |
|---|---|---|
| 结构可推断 | 模块关系、前后依赖足够清晰 | 直接推演，标 E2 |
| 方法论可推断 | 该领域有稳定常见做法 | 直接推演，标 E3 |
| 低影响未知 | 不影响主流程复现 | 放入假设表，不追问 |
| 可反证未知 | 影响主流程，但可通过删步/替代路径验证 | 先推演，后反证 |
| 高影响不可验证 | 影响主流程，且无证据、无方法论可推 | 追问用户 |

## 4. 追问格式

追问必须带假设，禁止开放式索取背景。

推荐格式：

```markdown
我观察到 [证据]，因此推测 [过程/方法论/判断]。
这个点会影响 [后续步骤/复现路径]。
请确认：是 [A]，还是 [B]，还是其他？
```

不合格问题：

- “能告诉我更多背景吗？”
- “你当时是怎么想的？”
- “这个过程具体是什么？”

## 5. 追问上限

- 每轮最多 3 个问题。
- 总共最多 2 轮。
- 超过后继续推进，标 E5 和置信度。

## 6. 主动推演输出格式

在需要继续推进但仍有未知时，使用：

```markdown
我先不追问，基于现有证据做主动推演：

| 推演项 | 依据 | 证据等级 | 置信度 | 后续验证 |
|---|---|---|---|---|
| ... | ... | E2/E3/E5 | 高/中/低 | 正向还原/删步反证/待确认 |

仅有以下高影响未知需要确认：
1. ...
```

## 7. 防访谈化检查

如果连续两次响应都在问问题，必须停下来自问：

- 是否已经能给出 70% 可信的第一版模型？
- 这些问题是否都满足追问门槛？
- 能否先标假设并通过反证验证？

如果答案是“能”，立即停止提问，开始推演。
