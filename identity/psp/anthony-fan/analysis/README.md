# PSP Analysis

这里放 PSP 生成和更新过程中的分析材料。

这些文件是 evidence analysis，不是最终 PSP，也不是唯一真源。最终 PSP 当前入口仍以 `identity/psp/anthony-fan/PSP.md` 和 `identity/psp/anthony-fan/current.yml` 为准。

写入规则：

- 只放 owner-approved 或 public-safe 的抽象分析。
- 不放原始私密正文、完整转写、客户资料、合同、secret。
- 如果分析结论进入 PSP，必须记录到 update log 或 changelog。
