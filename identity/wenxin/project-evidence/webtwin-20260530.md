## Project Purpose

WebTwin / Website Extractor is a Python-based tool for extracting websites and packaging their HTML, CSS, JavaScript, images, fonts, metadata, and component structure into organized artifacts.

The project is framed for:

- website study and archiving;
- UI/component analysis;
- AI-agent training data preparation;
- design reference and Cursor/AI-assisted modification workflows.

## Artifact Summary

Architecture signals:

- Flask web server as interface and API endpoint.
- Requests-based HTTP retrieval for normal pages.
- Selenium renderer for JavaScript-heavy and dynamic pages.
- BeautifulSoup/content parser for asset and metadata discovery.
- Asset downloader and ZIP creator for organized output packaging.
- Explicit handling of dynamic content, lazy loading, URL normalization, duplicate assets, anti-bot issues, and WebDriver reliability.

Workflow signal:

```text
URL -> extraction/rendering -> HTML parsing -> asset discovery -> asset download -> ZIP package -> downstream AI/Cursor analysis
```
