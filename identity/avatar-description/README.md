# Avatar Description

This directory contains the product-facing current Avatar description.

`current.yml` is the first file a studio, runtime handbook, or human-facing dashboard should read when it needs to answer: "What is the current digital avatar like?"

It is a structured summary derived from Wenxin, PSP, Soul, and Design. It is not a replacement for those evidence artifacts.

For a full third-person avatar page, use `docs/avatar-page-information-architecture.md`. That page model explains which sections are supported by current openLifeOS artifacts and which sections remain missing or weak.
