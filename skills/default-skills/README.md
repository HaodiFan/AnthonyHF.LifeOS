# Default Skills

`skills/default-skills/` 保存 openLifeOS 内置 Skill，不是用户后续蒸馏出来的个人能力仓库。

当前内置 self-evolution Skills：

- `self-evolution/wenxin/`：问心，自我发现与定位。
- `self-evolution/psp/`：PSP/person model，人物模型与分身边界。
- `self-evolution/ipo-reverse/`：IPO Reverse，从完成产出反推过程、方法论和可复用 Skill。

用户自己的 runtime skill 或 distilled meta skill 默认进入 `skills/`。
