# 电商行业 · 暖场题库

适用于用户声称做过"电商运营"、"电商 BI"、"品牌电商"、"电商技术"、"电商数据分析"等。

---

## 该领域的"内行黑话"

- **四大平台**：抖音、天猫、拼多多、京东
- **平台运营术语**：日销 / 周销 / 月销、客单价、UV / PV、CTR、CVR、ROI、ROAS
- **节点**：618、双 11、38 节、99 大促、年货节、双 12
- **店铺类型**：旗舰店 / 专卖店 / 专营店、企业店 / 个人店
- **数据术语**：GMV / 流水 / 实收、退款率、复购率、加购率、收藏率
- **品牌生态**：tier 1 国际品牌 / 国货头部 / 新锐品牌
- **平台流量**：自然流量 / 付费流量 / 内容流量 / 推荐流量
- **常见痛点**：库存周转、爆款依赖、平台佣金、广告投流 ROI、退货率

## 暖场题

### 题目 1（最推荐 · 区分度最高）

**问法**：

> 你刚才说做过电商。我好奇问下——618 和双 11，你客户里哪个节点更重要？为什么？

**圈内人 1 秒答出的特征**：
- 立即区分**品类**（"看品类"、"做美妆 / FMCG 的话双 11 更重要"、"做 3C 大家电的可能 618"）
- 提到**平台差异**（"双 11 是天猫的主场"、"618 是京东的主场"）
- 带**经验感**（"今年 618 整体不如去年"、"双 11 越来越长，从原本一天变成一个月"）

**圈外人卡壳的表现**：
- 笼统说"双 11 大"或"差不多吧"
- 不能区分品类
- 用"听说"语气
- 完全不答

**反伪信号**：
- 如果答"看品类"+ 给出具体品类的判断 → **真在行**
- 如果答"双 11 大、618 小" → 接触过但非深度做过
- 如果答"差不多 / 不知道 / 都重要" → 可能没真做过电商运营

---

### 题目 2（次推荐 · 验证平台分布）

**问法**：

> 你客户在抖音、天猫、拼多多、京东 这四个平台里，哪个销售占比最大？为什么？

**圈内人答出的特征**：
- 直接说出**具体占比**（"天猫占 60%、抖音 30%、拼多多和京东各 5%"）
- 说出**为什么是这个分布**（"因为客户是国际品牌，主战场天猫"、"抖音是增长最快的"）
- 提到**平台特性差异**（"拼多多更适合白牌"、"抖音内容驱动"）

**圈外人卡壳**：
- 笼统答"四个都有"
- 顺序不对
- 不能解释为什么

**反伪信号**：
- 如果答"具体占比 + 为什么" → 真做过
- 如果答"主要做天猫" → 可能只做过一个平台
- 如果答不出占比 → 可能没真接触过运营数据

---

### 题目 3（验证 BI / 数据角度）

**问法**：

> 给品牌做电商数据分析时，最常被问到的问题是什么？

**圈内人答出的特征**：
- 提到**业务问题而非技术问题**（"为什么 GMV 下滑"、"为什么这个 SKU 卖不动了"、"竞品在做什么"）
- 提到**对比维度**（"和上周比 / 和去年同期比 / 和竞品比"）
- 提到**具体场景**（"双 11 前要做品类规划"、"日常要看促销 ROI"）

**圈外人卡壳**：
- 答抽象的"数据分析"
- 答技术工具问题（"用什么 BI 工具"——这是技术视角，不是业务视角）

**反伪信号**：
- 答业务问题 + 具体场景 → 真做过 to B 服务
- 答技术工具问题 → 可能是技术人员没接触过业务
- 答不上来 → 可能没真做过这个工种

---

### 题目 4（高判别 · 验证 tier 1 客户经验）

**问法**：

> 服务过国际品牌（比如欧莱雅、宝洁这种）的电商团队和服务过国内品牌（比如完美日记、花西子这种）的电商团队，做事方式有什么不同？

**圈内人答出的特征**：
- 提到**决策速度差异**（国际品牌慢、国内快）
- 提到**预算和合规**（国际严苛、国内灵活）
- 提到**团队结构**（国际有 global 总部约束、国内一把手能拍板）

**圈外人**：
- 答得抽象（"国际品牌更专业"、"国内品牌更灵活"——这是没实际接触的回答）

**反伪信号**：
- 答出具体差异 → 真服务过 tier 1
- 笼统回答 → 可能是听说，没真做过

---

### 题目 5（验证 LLM/AI 应用经验）

**问法**：

> 你说做过 BERT 微调和 LLM。在电商场景里，BERT 时代你解决了什么问题，LLM 时代换了什么解法？

**圈内人答出的特征**：
- 提到**具体场景**（评论分类、搜索意图理解、客服自动化、商品标题生成）
- 区分两个时代的**解法差异**（BERT 需要标注数据微调，LLM 直接 prompt 或少量样本）
- 提到**成本和精度的权衡**

**圈外人**：
- 答得概念化（"BERT 不行了，LLM 更好"）
- 没有具体场景

**反伪信号**：
- 答出场景 + 解法演进 → 真在做这条线
- 没有具体场景 → 可能是听说
