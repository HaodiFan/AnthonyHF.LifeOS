# 问心 · 金字塔输出模板

> **核心心法**：人脑的接收信息方式是**先记标签 → 再读一句 → 再看图 → 才愿意读细节**。
> 这份模板的结构必须**符合接收顺序**，不是按"评估完整性"。

> **如果把这份内容做成网站**：默认使用 **GSAP + scroll-driven transitions**，并按"总览先行、细节后释"的顺序渐进式呈现；不要把整份报告在第一页一次性铺完。

> **输出前门禁**：核心项目剖面已完成；差异化价值已回答；MBTI 已追踪、测试或由用户明确跳过。否则只能输出临时画像。
