# IPO Reverse Skill

IPO Reverse is a self-evolution Skill for reconstructing expert cognitive process from completed artifacts.

It reverse-engineers:

- artifact evidence
- hidden cognitive tasks
- methodology selection and rejection
- intermediate thinking assets
- process chain
- final Input / Process / Output packaging

Use it when a finished document, proposal, codebase, conversation, or system design needs to become an SOP, training material, Skill blueprint, or reproducible methodology.
