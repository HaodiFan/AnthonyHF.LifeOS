怎么读

这个 skill 不等于“小红书文案”。它的上层能力是把真实材料变成长期可复用的公开叙事系统。

输入

聊天想法、创业判断、产品物料、实验记录、公开身份变化、方法论草稿或发布反馈。

路由

先判断叙事层级、资产对象、来源路由和公开风险，再决定写 intake、series、product、draft 或 review。

产出

intake、系列 brief、产品页、口播稿、文章、封面文案、发布包、风险扫描、复盘记录。

边界

不复制私密证据、不编造客户数据、不把实验说成完成式结论、不把产品写成硬广清单。
