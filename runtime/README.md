# Runtime 运行现场

这里承载 AnthonyHF.LifeOS 的活动现场：sessions、runtime skills 和 runtime lessons。

Runtime 只记录任务执行的公开安全索引。实际产出可指向 `artifacts/`、`docs/`、`work/`、项目 repo 或外部 private authority source。观察和 lesson 先进入 `runtime/runtime-lessons/`，再由 `evolution/` 判断是否升级为能力、身份更新或工作索引。

## 子目录

- `sessions/`：任务、对话、执行流的公开安全索引。
- `runtime-skills/`：运行期可调用或候选 skill 的索引。
- `runtime-lessons/`：运行中产生的 lesson-event 和复盘入口。
- `runtime-profile/`：本 LifeOS 的运行期画像占位，记录当前可用上下文、近期限制和 adapter 状态；不是长期人格模型。
- `profiles/`：OpenClaw、Hermes 等外部 runtime 的生成投影；不是真相源。
