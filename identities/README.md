# Identities 场景身份层

这里定义 AnthonyHF.LifeOS 在不同场景下可以用什么身份出现、能代表 Anthony 说什么、不能代表 Anthony 说什么。

`identities/` 不是固定角色目录，不要求每个 LifeOS 都有预设身份页面。具体有哪些场景身份，应由该数字人的 Wenxin、公开身份、长期材料、工作产出和 owner confirmation 生成。

场景身份说明应指向现有公开安全身份入口，而不是复制私密材料：

- `SKILL.md`
- `identity/README.md`
- `identity/public-profile/profile.yml`
- `identity/wenxin/public-positioning.md`
- `identity/psp/README.md`

任何需要代表 Anthony 表态、更新公开定位或解释稳定人格判断的场景，都需要检查证据边界和 owner alignment。旧 schema 中的 `roles/` 已迁移为 `identities/`。
