# Self Evolution Skills

Self-evolution skills update what this avatar knows about itself.

Expected slots:

- Complete Wenxin self-discovery skill lives at `evolution/organ-systems/wenxin/` and updates `identity/wenxin/`.
- Complete PSP/person model skill lives at `evolution/organ-systems/psp/` and updates `identity/psp/anthony-fan/`.
- Complete IPO Reverse skill lives at `evolution/organ-systems/ipo-reverse/`; it turns finished outputs into retrospective evidence maps, hidden cognitive tasks, middle-layer artifacts, and reproducible IPO.
- Cognitive alignment skill: compares inferred lessons with owner judgment and decides whether evidence may update a runtime skill, memory, PSP, or distilled meta skill.
- Memory indexing skill: updates `memory/` entrypoints.
- Hermes sync skill: turns new approved evidence into updates for Wenxin, PSP, skill recommendations, memory index, and root routing.

Upgrade rule:

- Runtime skills produce task evidence and lessons.
- IPO Reverse reconstructs the hidden process and reusable IPO from completed work.
- Cognitive alignment decides whether the inferred rule is real, recurring, privacy-safe, and worth promoting.
- Only then may a lesson upgrade a distilled meta skill such as `engineering-everything`.

Do not add Wenxin, PSP, or IPO Reverse folders here. They create duplicate skill discovery paths. Install the complete repos under `skills/self-evolution/`.
