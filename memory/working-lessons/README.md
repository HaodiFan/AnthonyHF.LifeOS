# Working Lessons

这里存放候选经验，不是长期记忆，也不是 Skill 正文。

Allowed:

- dated lesson with evidence pointer;
- short-term project constraint;
- hypothesis that needs review;
- user correction that may affect future behavior.

Forbidden:

- reusable step-by-step workflow;
- raw private transcript;
- stable identity or preference without provenance.

Promotion:

- factual and stable -> `memory/long-term/`;
- multi-source claim -> `memory/distilled-knowledge/`;
- repeatable procedure -> `skills/runtime/` proposal;
- reusable judgment -> `skills/meta/` proposal after IPO Reverse and owner alignment.
